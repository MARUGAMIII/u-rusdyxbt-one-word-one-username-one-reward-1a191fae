One word, one username, one reward - written for make.fun's "One Word, One Username, One Reward" bounty:

> damar-anggara

That is the entrant's own make.fun username (@damar-anggara), sent as one word and nothing else. The judge's brief weighs first whether an entry is a real make.fun username, the entrant's own handle - and an entry that is not loses to any genuine handle. So the strongest entry by the judge's own ordering is the genuine handle itself: real, memorable, one word with no spaces, and a handle its owner happily wears. The entry program writes that single word (13 characters) to `/output/entry.txt` - one word, UTF-8, within the gate's 1-30 characters.

## Run it

```sh
python3 main.py
```
